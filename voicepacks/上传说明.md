# 模型分发部署说明（当前方案）

模型整包放在你的服务器上，App 从服务器下载并解压。

```
http://8.130.169.254/tts/
├── xiaoya.zip         13.13 MB   小雅音色（默认）
├── chaowen.zip        13.15 MB   超文音色
├── aishell3.zip       31.89 MB   百变声音包
├── asr.zip            19.98 MB   语音识别模型
└── voice-sources.json    246 B   源清单
```

## 已验证

| 项目 | 结果 |
|---|---|
| 四个 zip 完整性 | 逐字节校验通过（13769076 / 13788275 / 33434658 / 20945582） |
| 断点续传 | 支持（`Range` 返回 206 + `Content-Range`） |
| HTTPS | **不通**（443 未开放，只开了 80） |
| App 侧放行 | 已在 `network_security_config.xml` 单独放行该 IP 的明文流量 |

## 需要做的一件事：覆盖上传 voice-sources.json

服务器上现在的 `voice-sources.json` 是空模板（`zip` 数组为空），
把 `D:\electronic\voicepacks\voice-sources.json` 覆盖上去（已填好四个地址）：

```json
{
  "v": 1,
  "packs": {
    "tts_xiaoya":   { "zip": ["http://8.130.169.254/tts/xiaoya.zip"],   "bytes": 13769076 },
    "tts_chaowen":  { "zip": ["http://8.130.169.254/tts/chaowen.zip"],  "bytes": 13788275 },
    "tts_aishell3": { "zip": ["http://8.130.169.254/tts/aishell3.zip"], "bytes": 33434658 },
    "asr":          { "zip": ["http://8.130.169.254/tts/asr.zip"],      "bytes": 20945582 }
  }
}
```

> 不覆盖也能用——App 内置了同样的地址。覆盖的意义是：将来 IP 或路径变了，
> 你改这个 JSON 就行，用户不用更新 App。

## 三层保险

```
1. 服务器上的源清单 → 随时可改，用户不用更新 App
2. App 内置地址（ModelRepo.BASE）→ 清单拉不到时使用
3. HuggingFace 官方源逐文件下载 → 前两层都挂时兜底
```

## 为什么不用蓝奏云

你上传的四个蓝奏云分享链接我解析出了直链，但**实际下载时返回的是阿里云盾反爬页**
（`acw_sc__v2` 挑战页），不是文件。带 Referer、带浏览器 UA 都一样。

蓝奏云的下载端点部署了 WAF，App 这种非浏览器客户端拿不到真文件
（除非在 App 里实现它的 cookie 计算，而那套算法一变就失效）。所以放弃。

同理，Gitee 的 raw 通道对公开仓库超过 10MB 强制认证，也放不了大文件
（Release 附件可以，但 Gitee 社区规范不提倡拿仓库当网盘）。

**结论：自建服务器是目前最合适的方案**——直出、支持续传、完全可控。

## 以后 IP 变了怎么办

1. 改服务器上的 `voice-sources.json`（立刻对所有用户生效）
2. 下次发版时同步改 `ModelRepo.BASE`
3. 如果换了域名并配了 HTTPS，记得把 `network_security_config.xml` 里的
   明文放行改成新域名，或整个删掉

## 建议（非必须）

给服务器配上 HTTPS（绑定域名 + Let's Encrypt 免费证书）。
现在为了能用 HTTP，App 里给这个 IP 开了明文放行——虽然只限这一个地址，
但 HTTPS 更干净，也不用担心运营商劫持篡改 zip 内容
（目前 App 有文件大小校验，被篡改会回退到官方源，不会装坏模型）。
